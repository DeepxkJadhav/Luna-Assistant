## 📲 How to Install on Android

### Method 1: Direct Phone Install (Recommended)
1. Download `Luna-Assistant-v1.0.0.apk` directly on your phone.
2. Tap the downloaded file in your browser or Files app.
3. If prompted, allow **"Install unknown apps"** from this source.
4. Tap **Install** and open **Luna**.

### Method 2: Via ADB (Computer to Phone)
With USB debugging enabled on your phone:
```bash
adb install -r Luna-Assistant-v1.0.0.apk
```

## ⚙️ Initial Setup & Permissions

Upon opening Luna for the first time:
1. **Accessibility Service:** Enable *Luna Accessibility Service* (required for screen perception & gestures).
2. **Display over other apps:** Grant overlay permission (required for the floating voice companion UI).
3. **Microphone:** Allow audio recording for voice conversations and offline "Wake up Luna" wake word.
4. **AI API Key:** Tap the `AutoAwesome` sparkle icon on the home screen to configure your Google Gemini, Claude, OpenAI, or Groq API key.
